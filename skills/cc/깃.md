# /cc:깃 — Git 워크플로우 매니저

> 사용자의 git 관련 요청을 자동 판단하여 실행한다.
> "커밋해줘", "동기화해줘", "올려줘" 등 자연어로 트리거된다.

## 입력
$ARGUMENTS

---

## Phase 0: 브랜치 안전 확인

1. 현재 브랜치를 확인한다
2. **현재 브랜치가 main/master이면** → "main 브랜치에서는 작업할 수 없습니다" 출력 후 **중단**
3. 작업 브랜치가 아닌 곳에 있으면 → 사용자에게 올바른 브랜치를 물어본다

## Phase 1: 상황 판단

아래 명령을 실행하여 현재 상태를 파악한다:

```bash
# 1. 현재 브랜치 확인
git branch --show-current

# 2. 변경사항 확인
git status
git diff --stat

# 3. 원격과의 차이 확인
git fetch origin
git log --oneline HEAD..origin/main   # main에 새 커밋이 있는지
git log --oneline origin/main..HEAD   # 내 커밋이 push 안 된 게 있는지
```

## Phase 2: 자동 분기

상황에 따라 아래 중 하나를 실행한다:

### A. 동기화 (origin/main에 새 커밋이 있을 때)

사용자가 "동기화", "가져와", "최신", "sync", "pull" 등을 말하거나,
origin/main에 현재 브랜치에 없는 커밋이 있을 때:

1. 로컬 변경사항이 있으면 `git stash`
2. `git merge origin/main` (Fast-forward 우선)
3. stash가 있으면 `git stash pop`
4. 충돌 발생 시 → **즉시 멈추고 사용자에게 물어본다**
5. 결과 보고 (가져온 커밋 수, 변경 파일 수)

### B. 커밋 (로컬 변경사항이 있을 때)

사용자가 "커밋", "올려", "commit", "push" 등을 말할 때:

1. `git status` + `git diff --stat` — 변경사항 확인
2. 프로젝트에 빌드 스크립트가 있으면 빌드 실행 — **빌드 실패 시 중단, 에러 보고**
3. 변경 파일을 분석하여 커밋 메시지 자동 생성
4. `git add` + `git commit`
5. 사용자가 "push", "올려" 등을 명시했으면 `git push origin <현재브랜치>`
6. 결과 보고

### C. 배포 (main으로 머지 + push)

사용자가 "배포", "deploy", "main에 올려" 등을 말할 때:

1. 먼저 **B (커밋)** 실행 (변경사항 있으면)
2. `git push origin <작업브랜치>`
3. `git fetch origin main && git checkout main && git merge <작업브랜치>`
4. 충돌 시 → **즉시 멈추고 사용자에게 물어본다**
5. `git push origin main`
6. `git checkout <작업브랜치>` — 복귀
7. 결과 보고

### D. 동기화 + 커밋 (둘 다 필요할 때)

origin/main에 새 커밋도 있고, 로컬 변경사항도 있을 때:

1. 먼저 **A (동기화)** 실행
2. 동기화 성공 후 **B (커밋)** 실행

---

## 절대 규칙

- **main/master 브랜치에서 직접 작업하지 않는다** — 반드시 작업 브랜치에서만
- **force push 절대 금지**
- **충돌은 자동 해결하지 않는다** — 반드시 사용자에게 물어본다
- `.env`, `.env.local`, 시크릿 파일은 커밋하지 않는다
- `git merge --abort`로 되돌릴 수 있는 상태를 항상 유지한다

## 결과 보고 형식

작업 완료 후 아래 형식으로 보고:

```
✅ [작업 유형] 완료
- 브랜치: <현재 브랜치>
- 커밋: [커밋 메시지]
- 변경: N개 파일 (+추가 -삭제)
- Push: 완료/미실행
```

## 사용 예시

```
/cc:깃                    # 상황 자동 판단
/cc:깃 커밋               # 변경사항 커밋
/cc:깃 동기화             # origin/main 가져오기
/cc:깃 올려               # 커밋 + push
/cc:깃 배포               # main 머지 + push
```
