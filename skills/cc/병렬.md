# /cc:병렬 — 병렬작업 오케스트레이터

> 작업을 받으면 의도를 확인하고, 관련 코드를 조사한 뒤, 크기에 따라 바로 실행하거나 병렬 지시서를 생성한다.

## 입력
$ARGUMENTS

---

## Phase 1: 의도 확인

작업 내용을 보고 사용자에게 **자연어로 확인**한다:

```
이렇게 진행하려고 합니다:

목표: [한 문장으로 요약]
예상 범위: [어떤 파일/기능이 영향받는지]
예상 크기: Small(1~3파일) / Medium(4~10파일) / Large(10+파일)

이대로 진행할까요?
```

사용자가 수정하면 반영. 확인되면 Phase 2로.

---

## Phase 2: 조사

**코드를 수정하지 않고 읽기만 한다.** 아래를 파악한다:

1. **관련 파일 목록** — 수정할 파일, 참고할 파일
2. **기존 패턴** — 비슷한 기능이 이미 어떻게 구현되어 있는지
3. **타입/스키마** — 타입 정의, DB 스키마에서 실제 컬럼명과 타입
4. **공유 파일** — 여러 작업자가 참조해야 할 파일

조사 결과를 바탕으로 Phase 3 판단.

---

## Phase 3: 크기 판단 & 분기

### Small (파일 1~3개) → 바로 구현

```
Small 작업입니다. 바로 구현합니다.
```

Phase 2에서 파악한 기존 패턴/타입을 따라 구현 → 빌드 확인.
**Phase 4 이하를 건너뛴다.**

### Medium (파일 4~10개) → 바로 구현 (확인 후)

```
Medium 작업입니다. 아래 순서로 구현합니다:
1. [파일/기능 A]
2. [파일/기능 B]
3. 빌드 확인
```

한 세션에서 순차 구현. 3파일 수정마다 빌드 확인.
**Phase 4 이하를 건너뛴다.**

### Large (파일 10개+) → 병렬 지시서 생성

```
Large 작업입니다 — 작업자 N명 ([역할A], [역할B], ...)
지시서를 생성합니다.
```

Phase 4로 진행.

---

## Phase 4: 분해 & 지시서 생성

### 분해 규칙
- **같은 파일을 두 작업자가 수정하면 안 된다**
- 같은 파일이라도 추가(append)만 하는 경우 허용 (예: 타입 파일에 각자 타입 추가)
- 공유 파일이 있으면 "읽기만" 하도록 지시
- 의존성 있는 작업은 순서 명시 ("A 완료 후 B 시작")

### 워커 수
- 독립 단위 수 = 워커 수
- 단, 작업량이 너무 적은 단위(파일 1~2개)는 옆 워커에 합친다

### 폴더 구조

`~/.cc-parallel/MMDD_[작업명요약]/`에 생성:

```
~/.cc-parallel/MMDD_[작업명요약]/
├── 작업자A_[역할].md
├── 작업자B_[역할].md
├── 작업자A_보고서.md    ← 워커가 완료 후 생성
└── 작업자B_보고서.md
```

### 지시서 템플릿

각 파일은 **자체 완결형** — 다른 프롬프트에 복붙하면 바로 작업 가능해야 한다.
**Phase 2 조사 결과를 구체적으로 채운다** — 빈 칸이나 [placeholder]를 남기지 않는다.

```markdown
# [작업자X] [역할명] 지시서
# 세션: [MMDD_작업명요약]
# 생성: [날짜 시간]

## 완료 후 보고

작업이 끝나면 `~/.cc-parallel/[세션폴더]/작업자[X]_보고서.md`에 저장:

\```
---보고서---
세션: [MMDD_작업명요약]
작업자: [X]
상태: 완료 / 부분완료 / 실패
완료항목:
  - [완료한 것]
미완료항목:
  - [못한 것] — 사유: [이유]
변경파일:
  - [파일경로]: [변경 내용 요약]
빌드결과: 통과 / 실패 (에러 내용)
주의사항:
  - [머지 시 주의할 점]
---끝---
\```

## Phase 5: 안내

```
## 병렬작업 준비 완료

폴더: [세션폴더 절대경로]

| 프롬프트 | 작업 내용 |
|---------|----------|
| 작업자A | [요약] |
| 작업자B | [요약] |

새 Claude Code 프롬프트를 [N]개 열고 각각 복붙:

**작업자A:**
`넌 작업자A야. 지시서를 읽고 작업해 [세션폴더 절대경로]`

**작업자B:**
`넌 작업자B야. 지시서를 읽고 작업해 [세션폴더 절대경로]`

모든 작업자가 끝나면:
`/cc:머지 [MMDD_작업명요약]`
```
